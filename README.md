  # Privacy Policy / プライバシーポリシー                                                                                                                             
                                                                                                                                                                      
  Last updated: 2025-XX-XX                                                                                                                                            
                                                                                                                                                                      
  ## Overview / 概要                                                                                                                                                  
                                                                                                                                                                      
  MugenCalendar（以下「本アプリ」）のプライバシーポリシーです。                                                                                                       
                                                                                                                                                                      
  ## Information We Collect / 収集する情報                                                                                                                            
                                                                                                                                                                      
  ### Local Data / ローカルデータ                                                                                                                                     
  本アプリは以下のデータを**端末内にのみ**保存します：                                                                                                                
  - カレンダーイベント                                                                                                                                                
  - カスタム休日設定                                                                                                                                                  
  - アプリ設定                                                                                                                                                        
                                                                                                                                                                      
  これらのデータは外部サーバーに送信されません。                                                                                                                      
                                                                                                                                                                      
  ### Calendar Access / カレンダーへのアクセス                                                                                                                        
  本アプリはiOSカレンダーとの連携機能を提供します。                                                                                                                   
  カレンダーへのアクセスはユーザーの明示的な許可が必要です。                                                                                                          
                                                                                                                                                                      
  ## Third-Party Services / 第三者サービス                                                                                                                            
                                                                                                                                                                      
  ### Google AdMob                                                                                                                                                    
  本アプリは広告配信にGoogle AdMobを使用します。                                                                                                                      
  AdMobは広告配信のためにデバイス情報を収集する場合があります。                                                                                                       
  詳細: https://policies.google.com/privacy                                                                                                                           
                                                                                                                                                                      
  広告削除オプションをアプリ内課金で提供しています。                                                                                                                  
                                                                                                                                                                      
  ### Nager.Date API                                                                                                                                                  
  祝日データの取得に使用します。国コードのみを送信し、                                                                                                                
  個人情報は一切送信しません。                                                                                                                                        
                                                                                                                                                                      
  ## Data Storage / データの保存                                                                                                                                      
                                                                                                                                                                      
  - すべてのユーザーデータは端末内に保存されます                                                                                                                      
  - iCloudバックアップの対象となる場合があります                                                                                                                      
                                                                                                                                                                      
  ## Children's Privacy / 子供のプライバシー                                                                                                                          
                                                                                                                                                                      
  本アプリは13歳未満の子供から意図的に個人情報を収集しません。
